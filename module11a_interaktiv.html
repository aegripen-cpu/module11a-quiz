Så här kör du quizet på iPhone:

Enklast (rekommenderas)

  1. Skicka filen till dig själv
    • Airdrop från datorn till iPhone, eller
    • Maila till dig själv, eller
    • Lägg den i iCloud Drive / Files
  2. Öppna på iPhone
    • Öppna filen i Files (Filer)
    • Tryck på filen → dela (rutan med pil) → Öppna i Safari
      (eller “Quick Look” och sedan öppna i Safari om det visas)
  3. Lägg till på hemskärmen (valfritt men bra)
    • I Safari: tryck dela → Lägg till på hemskärmen
    • Då fungerar den mer som en app (helskärm, egen ikon)

Alternativ

MetodSå gör du
AirDropDator → högerklicka filen → Dela → AirDrop → din iPhone → Öppna i Files/Safari
MailBifoga HTML-filen → öppna bilagan på iPhone → “Öppna i Safari”
iCloud DriveSpara i iCloud → Files-appen på iPhone → öppna → Safari
USBAnslut iPhone till dator → kopiera till Files via Finder (macOS)

Tips för mobil

  • Använd Safari (bäst stöd för den här typen av HTML/JS).
  • Lås skärmorientering om du vill (liggande kan vara bekvämare vid många frågor).
  • Timern och allt fungerar offline när filen väl är öppnad – ingen internet behövs efteråt.

Om du inte hittar “Öppna i Safari” när du trycker på filen: tryck Dela → bläddra bland appar → Safari.

OneDrive på iPhone är ofta krånglig med .html-filer – den vill sällan öppna dem i Safari. Prova något av de här sätten:

1. Mail (enklast och mest pålitligt)

  1. På datorn: bifoga i ett mejl till dig själv.
  2. På iPhone: öppna mejlet.
  3. Tryck på bilagan och håll inne (eller tryck Dela).
  4. Välj Safari / Öppna i Safari.

Om den bara visas som text: tryck Dela → Spara i Filer → öppna sedan från Filer (se punkt 3).

2. AirDrop (om du har Mac)

  1. På Mac: högerklicka filen → Dela → AirDrop → din iPhone.
  2. På iPhone: acceptera → öppna i Filer eller direkt i Safari.

3. Via Filer-appen (efter att filen ligger i OneDrive)

  1. Öppna Filer på iPhone.
  2. Under Bläddra → OneDrive (måste vara inloggad).
  3. Hitta .
  4. Tryck på filen.
  5. Om den inte öppnas bra: tryck … (eller Dela) → Öppna i / Öppna i Safari.

Ibland måste du först ladda ner filen (molnikon med pil) så den finns offline i Filer.

4. Om inget “Öppna i Safari” syns

  1. Spara filen till iCloud Drive eller På min iPhone via Filer.
  2. Öppna Safari.
  3. I adressfältet skriv inget – gå till bokmärken fungerar inte direkt.
  4. Bättre: i Filer → tryck och håll på filen → Dela → bläddra fram Safari.

5. Snabb nödlösning – byt “förpackning”

Om iPhone vägrar .html:

  1. På datorn: döp om filen till
    Module11A_Interaktiv.txt
  2. Skicka/spara den till iPhone.
  3. Öppna den, kopiera allt innehåll.
  4. Det är krångligare – mail + Safari är bättre.

Rekommendation: Skicka filen till dig själv via Mail från datorn och öppna bilagan i Safari. Det brukar fungera när OneDrive strular.

Grok

Det beror nästan alltid på var filen ligger – inte på själva quizet. Quizet har inget lösenord inbyggt.

Om det är Netlify

  • Netlify Drop ska ge en öppen länk utan lösenord.
  • Om du skapat ett projekt/team kan “Password protection” eller “Visitor access” vara påslaget.

Fix:

  1. Gå till app.netlify.com och logga in.
  2. Öppna din site → Site configuration / Settings.
  3. Leta efter Password protection, Visitor access eller Identity → stäng av.
  4. Eller gör en ny Drop: app.netlify.com/drop → dra in filen igen → använd den nya länken.

Om det är OneDrive / SharePoint

Då är det Microsoft som kräver inloggning. HTML-filer därifrån öppnas ofta dåligt på iPhone.

Gör så här i stället:

  1. Ladda ner till datorn.
  2. Gå till app.netlify.com/drop (utan att logga in om det går).
  3. Dra in filen (eller en mapp som bara innehåller den).
  4. Kopiera länken du får (t.ex. https://något-namn.netlify.app).
  5. Öppna den i Safari på iPhone – ska inte be om lösenord.

Om det är GitHub

  • Privat repo → lösenord/inloggning.
  • Gör repot Public och aktivera GitHub Pages, eller använd Netlify Drop i stället.

Kort: Använd en ny Netlify Drop-länk och undvik OneDrive som “webbhotell”. Då ska iPhone kunna öppna quizet direkt utan lösenord.
